# 旅行类标题风格指南

来源：用户提供的《旅行类标题参考.csv》（约百条）。以下为从样本归纳的写法，不代表素材事实。

## 核心气质

- 短、口语化、有画面；以一个“怎么会这样”的奇点抓住注意力。
- 将自然、建筑、城市、地貌拟人化或生活化，但标题仍指向可解释的真实现象。
- 常用问句、反问、引号和反差；不把信息写成新闻摘要。

## 优先句式

1. **主体也会 + 异常动作？**
   - 树也有朋友圈？
   - 冰也能发电？
   - 水往山顶流？
2. **地点/事物 + 为何/咋 + 反常结果？**
   - 西湖为何没栏杆？
   - 大桥为何不修直？
   - 房子咋“跑”了？
3. **带引号的具象比喻**
   - 荒漠里的“海”
   - 天然“大冰箱”
   - 沙漠也“变脸”
4. **最/唯一/像 + 强辨识标签**（仅事实已核验时）
   - 最不像地球的地方
   - 中国唯一没有的地貌
5. **反转或设问式惊奇**
   - 这世界咋反了？
   - 古人也爱打卡？
   - 掉进盐湖的车会消失？

## 选词与节奏

- 多用：也、咋、为何、还能、居然、长、会、跑、睡、唱、走。
- 优先名词和动词：冰川、瀑布、沙漠、盐湖、岩石、城市 + 燃、晃、长、褪色、行走。
- 一个标题只保留一个引号焦点；不混用多种夸张。
- 同批避免重复“也会”“最”“为何”“像地球”等开头。

## 避免

- 空泛：绝美风景、震撼奇观、旅行必去。
- 过长：把地点、成因、历史、数据同时写进标题。
- 失实：将普通地貌说成外星遗址、UFO 或灾害；将推测写成结论。
- 歧义：为押韵或玩梗而让读者无法知道主体是什么。

## 快速示例

素材：盐湖中有白色盐结晶，形似兔子。

- 盐湖长“白兔”？
- 湖里藏着一群“白兔”
- 这片盐湖会“养兔”？

素材：一座建筑因结构会在风中轻微摆动。

- 这栋楼一直在晃？
- 高楼也会“摇摆”？
- 大楼为什么会动？
